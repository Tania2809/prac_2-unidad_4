# Práctica 2 Unidad IV — Dos sitios web

Incluye:
1. `portfolio/` — Portafolio profesional personal.
2. `cafeteria/` — Sitio web de Café Aurora.

Ambos incluyen HTML, CSS y JavaScript, diseño responsivo, menú, modo oscuro y cambio ES/EN.

## Fotografías
La práctica indica que las fotografías deben ser originales y tomadas por cada alumno. Por eso el proyecto incluye referencias a archivos locales dentro de `images/`, pero NO imágenes descargadas de Internet.

### Portfolio
Agrega:
- `portfolio/images/foto-profesional.jpg`

### Cafetería
Agrega:
- `cafeteria/images/hero-cafe.jpg`
- `cafeteria/images/producto-1.jpg` ... `producto-6.jpg`

Puedes agregar más fotografías y sustituir las tarjetas "Foto 1", etc. del catálogo por tus fotografías reales.

## Ejecutar localmente
Abre `index.html` en un navegador o usa VS Code + Live Server.

## Despliegue
Los sitios son estáticos y pueden desplegarse en Docker, AWS, Azure o Google Cloud. La práctica solicita seleccionar plataformas de alojamiento y documentar el procedimiento y las capturas de evidencia.

## Nota
El formulario funciona como demostración y no envía correos a un servidor todavía. El mapa usa Google Maps embebido.
